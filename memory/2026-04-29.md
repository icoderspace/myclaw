## 重要学到的

- **OpenClaw "steer" ≠ 排队**：是 turn 还在进行时插入新消息，会显示成 steer。功能上不丢，但 UI 看着别扭。
- **会话 token 累积越大，回复越慢** —— 主观感觉像"排队"。Opus 模型比 Sonnet 慢 2-3 倍。建议长任务后开新会话 + 切 Sonnet。
- **ADO 的 PAT 不能用 PAT 自己续期** —— 必须人工操作或用 AAD token 调 lifecycle API（被 device code 禁用挡住了）。
- **ADO 权限模型分层**：org user → license (Basic vs Stakeholder) → project 成员 → repo 权限，缺一不可。
- **Stakeholder license 不能访问 git repo**，文档明文。
